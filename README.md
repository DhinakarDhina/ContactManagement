# ContactHub – Contact Management Application

A modern, responsive, and user-friendly Contact Management Web Application built using React.js.  
The application enables users to efficiently manage contacts with features such as searching, filtering, adding, editing, deleting, and viewing contact details.

---

## 📌 Project Overview

This project was developed as part of a Frontend Developer Internship Assignment to demonstrate:

- Component-based architecture
- State management
- Form handling & validation
- CRUD operations
- Responsive UI design
- Clean code structure and reusable components

---

## ✨ Features

### 📋 Contact Management
- Create new contacts
- Update existing contacts
- Delete contacts with confirmation
- View detailed contact information

### 🔍 Search & Filter
- Real-time search functionality
- Search by:
  - Name
  - Email address
- Filter contacts by status:
  - All
  - Active
  - Inactive

### ✅ Form Validation
- Required field validation
- Email format validation
- Phone number validation
- Error handling with user-friendly messages

### 🎨 Responsive User Interface
- Mobile-friendly design
- Clean and intuitive layout
- Proper loading, empty, and error states

| Technology | Purpose |
